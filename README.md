# TickWars | A Text-Based Browser MMORPG Game
A Game where you influence yours, others and the global tick to your own strategical advantage.

### DEVELOPMENT BRANCH
Make sure to set up the relevant ENV Vars for your local environment.

- Schemas are generated by Gorm based on the struct i have set out.This way ensures the tables are effectively type-safe in context of the rest of the project, before we start entering crappy data in them.
